# Spokewise FLOWS

1. Launch → seed if needed → the polar spoke map, which is the root.
2. Pill chips re-read the same map as Tension / Dish / True. They never push a screen.
3. Tap a spoke on the map → dial its value → the map redraws with the new reading.
4. Nav bar title switches wheel; the hero destination chrome reaches Bench / Wheel / Workshop; the gear opens Settings only.
5. Bench: spoke-length triangle, component bench, tensiometer curve.
6. Wheel: runout trace, build ledger thumbnails, two-wheel overlay, statistics.
7. Workshop: lacing pattern index, service log, settings → CSV tension sheet → ShareLink.
